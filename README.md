AI Lead Hunter

Автоматизований n8n workflow для пошуку потенційних клієнтів для веб-студії.

Система щодня шукає локальні бізнеси в Україні через Google Places API, визначає компанії без повноцінного сайту, перевіряє дублікати, передає кандидатів на AI-кваліфікацію та надсилає відібрані ліди в Telegram.

Основні етапи

- Search Generation — формує комбінації міст, категорій і пошукових модифікаторів. Запити ротуються між днями, щоб поступово охоплювати всю базу.
- Google Places — отримує назву, адресу, телефон, рейтинг, відгуки, сайт та інші дані бізнесу.
- Filtering — відкидає закриті бізнеси, дублікати та компанії, які вже мають повноцінний сайт.
- Memory — Data Table зберігає вже знайдені компанії, тому один бізнес не потрапляє у звіт повторно.
- AI Qualification — OpenAI оцінює потенціал ліда, визначає, чи потрібен йому сайт, формує "lead_score", причину та рекомендацію щодо типу сайту.
- Fallback — якщо AI недоступний або повертає некоректну відповідь, використовується резервний алгоритм оцінки.
- Telegram — формується структурований звіт із новими лідами та надсилається в Telegram.

Project Goal

Автоматизувати процес пошуку та первинної кваліфікації потенційних клієнтів замість ручного збору лідів.
